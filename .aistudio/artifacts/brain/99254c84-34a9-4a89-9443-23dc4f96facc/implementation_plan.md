# خطة تأمين وتطوير منصة البطة الصفرا SMM (Admin Security, Full Services & Control)

خطة هندسية دقيقة لإصلاح الأمان بالكامل، وتأمين وصول المشرف عبر مسار مخصص وصفحة تسجيل دخول مشددة، واستيراد كافة خدمات مزود SMMFansFaster مع هامش الربح، وتوسيع لوحة تحكم المشرف لتشمل إدارة كلمات سر وحسابات المستخدمين، وتعديل وحذف الخدمات، والتحكم في بوابات الدفع المصرية.

---

### قرارات المستخدم والخيارات المعتمدة

> [!IMPORTANT]
> استناداً إلى ردود المستخدم في مرحلة الاستيضاح، تم اعتماد المتطلبات الأمنية والوظيفية التالية:

1. **تأمين لوحة المشرف ومسار الدخول**:
   - تخصيص مسار مستقل `/admin` في المتصفح.
   - إذا لم يكن المستخدم مسجلاً كأدمن، يتم نقله تلقائياً لصفحة **تسجيل دخول المشرف المخصصة (Admin Login Gate)** التي تطلب اسم مستخدم وكلمة مرور المشرف حصراً.
   - إزالة أي أزرار للتبديل السريع بين الأدمن والعميل من الواجهة، وإلغاء المعلمات التجريبية (`current_user_id`) من الخادم لمنع أي تخطي أمني.
2. **استيراد وتحديث كافة الخدمات**:
   - إزالة القيود العددية السابقة (التي كانت تكتفي بأول 100 خدمة) وجلب واستيراد **كافة الخدمات المتاحة لدى المزود SMMFansFaster** مع تطبيق هامش الربح (Margin %) وسعر الصرف بالجنيه المصري تلقائياً.
3. **أدوات تحكم المشرف الموسعة (User & Service Controls)**:
   - **التحكم بالمستخدمين**: تغيير كلمة مرور أي مستخدم عند نسيانها، إيقاف/تجميد الحسابات المسيئة، تفعيل الحسابات، وتعديل الأرصدة مع تسجيل سبب العملية.
   - **التحكم بالخدمات**: إمكانية تعديل اسم وسعر وحدود أي خدمة، حذف الخدمات غير المرغوبة، وتفعيل/تعطيل كل خدمة بضغطة زر.
   - **التحكم بالمدفوعات المصرية**: تعديل أرقام فودافون كاش، إنستاباي، أورانج كاش، اتصالات كاش، وي باي، وفوري مباشرة من لوحة المشرف وحفظها بالخادم.

---

### 1. الهندسة الأمنية ومسارات التطبيق (Security & Route Architecture)

- **حماية المسارات (Route Guarding)**:
  - التحقق من عنوان URL في المتصفح (`window.location.pathname === '/admin'`).
  - في حال طلب العميل أو الزائر للمسار `/admin` دون جلسة أدمن صالحة، تظهر شاشة دخول المشرف المحمية بكلمة المرور المشفرة.
  - لن يظهر أي رابط أو زر يتيح للعميل العادي التبديل إلى أدمن.
- **تأمين الخادم (Backend Hardening)**:
  - تنظيف دالة `getAuthUser` في `server.ts` من أي تجاوزات عبر الـ Query Params (`current_user_id`) أو الـ Headers غير الآمنة (`x-user-id`, `x-user-role`).
  - فحص جلسة الـ Cookie فقط وفك تشفيرها للتأكد من أن `role === 'admin'`.
  - كافة مسارات `/api/admin/*` ترفض أي طلب لا يملك توثيق أدمن برمز خطأ `403 Forbidden`.

---

### 2. استيراد كافة خدمات مزود SMMFansFaster

- **توسيع مسار المزامنة `/api/admin/provider/sync-services`**:
  - جلب القائمة الكاملة لكافة الخدمات من API المزود (`action=services`).
  - ربط وتصنيف كافة الخدمات مع منصاتها (Instagram, TikTok, YouTube, Facebook, Telegram, X/Twitter, وغيرها).
  - احتساب سعر البيع بالدولار والجنيه تلقائياً: `Client Rate = Provider Rate * (1 + Margin% / 100)`.
  - تخزين واسترجاع الخدمات في قاعدة البيانات الثابتة (`yellow_duck_db.json`) مع الحفاظ على أي خدمات مخصصة تمت إضافتها محلياً.

### 3. أدوات وتحكمات لوحة المشرف (Admin Control Suite)

```
┌────────────────────────────────────────────────────────────────────────┐
│                   لوحة تحكم المشرف (Admin Dashboard Suite)             │
├────────────────────────────────────────────────────────────────────────┤
│ 1. إدارة المستخدمين:                                                   │
│    - زر إعادة تعيين / تغيير كلمة مرور المستخدم (Reset Password)        │
│    - زر حظر / إيقاف الحساب (Suspend / Ban) وزر إلغاء الحظر             │
│    - تعديل الرصيد (إيداع / خصم) مع كتابة سبب العملية                  │
│                                                                        │
│ 2. إدارة الخدمات:                                                      │
│    - زر تعديل تفاصيل الخدمة (الاسم، السعر، الحدود، القسم)               │
│    - زر حذف الخدمة نهائياً (Delete Service) مع تأكيد الحماية           │
│    - زر تبديل حالة الخدمة (نشط / معطل) بضغطة واحدة                     │
│    - فلترة وبحث سريع حسب المنصة أو الاسم                               │
│                                                                        │
│ 3. إدارة بوابات الدفع المصرية:                                         │
│    - تعديل أرقام محافظ الكاش (Vodafone, Orange, Etisalat, WE, InstaPay)│

│                                                                        │
│ 4. إدارة مزود SMMFansFaster:                                          │
│    - فحص الاتصال والرصيد الحي، ومزامنة كافة الخدمات، ومزامنة الطلبات    │
└────────────────────────────────────────────────────────────────────────┘
```

### 4. مسار التنفيذ الهندسي المتكامل (Step-by-Step Implementation)

1. **إصلاح الأمان في الخادم (`server.ts`)**:
   - إزالة ثغرة `current_user_id` و `x-user-role` من `getAuthUser`.
   - إضافة مسار `POST /api/admin/users/:id/reset-password` لتغيير كلمة سر المستخدم من الإدارة.
   - إضافة مسار `PUT /api/admin/users/:id/status` لتغيير حالة المستخدم (active / deactive / banned).
   - إضافة مسار `PUT /api/admin/services/:id` و `DELETE /api/admin/services/:id`.
   - إضافة مسارات `GET /api/admin/payment-methods` و `PUT /api/admin/payment-methods/:id`.
   - تعديل مسار `POST /api/admin/provider/sync-services` ليعالج كافة الخدمات دون تحديد حد 100 خدمة.

2. **تأمين واجهة المستخدم والمسار `/admin` (`App.tsx` & `Header.tsx`)**:
   - إزالة زر التبديل السريع نهائياً.
   - فحص المسار `/admin` في المتصفح وإظهار `AdminLoginPage` عند عدم وجود جلسة أدمن.
   - عند تسجيل دخول الأدمن، يتم التوجيه حصراً للوحة المشرف وتأكيد الجلسة.

3. **تطوير واجهة لوحة المشرف (`AdminDashboard.tsx`)**:
   - نافذة مودال لتغيير كلمة مرور أي مستخدم.
   - خيارات حظر وتفعيل المستخدمين وتعديل الرصيد مع سجل الأسباب.
   - جدول خدمات تفاعلي مع إمكانية البحث، الفلترة، الحذف، التعديل، والتعطيل.
   - واجهة تحكم كاملة بأرقام وسائل الدفع المصرية وحالاتها.

4. **الفحص والتحقق الكامل**:
   - اختبار تسجيل دخول المشرف والعميل، التحقق من عدم إمكانية دخول العميل للأدمن، والتأكد من نجاح البناء `npm run build` واختبار الأمان.
